2. Explain
Ans:
App
An App in Salesforce is a collection of related tabs, objects, and tools designed for a specific business purpose. Apps help users access everything they need in one place. Examples include Sales App, Service App, and Marketing App.
Example:
A College Management App can contain Student, Faculty, Course, and Admission objects.
Object
An Object in Salesforce is similar to a database table that stores information. Each object contains records and fields. Salesforce has standard objects like Account and Contact, and custom objects created by users.
Example:
Student Object stores student details such as name, roll number, course, and email.
Tab
A Tab is the user interface used to open and access objects, reports, dashboards, or applications in Salesforce. Tabs make navigation easy for users.
Example:
The Student Tab allows users to open and manage student records.

3. Difference Between Configuration and Coding
Ans:
Configuration and Coding are two different ways of customizing Salesforce. Configuration means creating features using clicks, settings, Flow Builder, validation rules, and other built-in tools without writing code. It is easier, faster, and mainly used for simple business requirements. Coding means using programming languages like Apex and Lightning Web Components to create advanced and complex functionality that cannot be achieved using configuration alone. Configuration is preferred whenever possible because it requires less maintenance, while coding is used when businesses need custom logic, integrations, or advanced automation.
